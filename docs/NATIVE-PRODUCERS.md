# 位置生产者复核与诊断 r3

2026-10-09。本轮围绕位置/法线生产者这一数据缺口推进。当前路线判断仍为“需要补充接口”，未进入原生光照效果修改。

## 已消除的推断风险

历史抓帧中，全屏材质 `415a922293923fa4` 的 t10 指向绘制 1704 的输出。生产者 PS 为 `edf9243383ddcd52`，VS 为 `77214b11a444acc8`。同次绘制的 t0 来自一次深度资源复制。此前绘制 1703 只输出零值，不能当独立几何位置。

原始 DXBC 经提取清单与 SHA 核对：位置 PS 读取 t0 深度、取 `max(depth, 0.000001)`，与 NDC.xy / 1 组成四维输入，乘 CB1[14–17] 的逆投影，再除以 w 输出 XYZ。VS 将裁剪位置 xy 直接传到该 PS。**这是一条深度重建链；用它生成的位置再投影回同一深度，会形成循环证据。**

`validate_native_position_producer.py` 真正执行原始 PS：两组非平凡合成输入与独立公式在 float16 存储误差内一致，改变深度确实改变输出；再用已采集的深度和相机进行 WARP 回放。现有实机位置的约 99.84% 像素 XYZ 逐分量相同，约 99.95% 在一 float16 ULP 内。该回放使用明确的 point/clamp 假设和消费者阶段数据，不能替代当前生产者身份、当时 sampler/CB 范围与输入阶段的实测。

法线有多次写入。历史全屏 t5 的最后绑定绘制为 `cb04f3ac25db2f85`，其输出含常量；此前还有大量几何 G-buffer 绘制。网格路径的最后候选是 `f8192a78678fdd96`。末次绑定不代表覆盖全部 RGB 像素，需要考虑输出槽、颜色写入掩码、混合、模板与几何覆盖。因此没有把最后一个 shader 命名为整张法线的唯一生产者。

## r3 补充的最小记录

- 目标快照携带最后观察到的 RTV 绘制 PS/VS 身份、帧/绘制序号、输出槽、视图格式与 mip/slice 范围、颜色写入掩码和混合启用状态。
- 记录同帧连续 RTV 写入次数，最多保留 16 个 PS 身份；超出明确标记截断。停用/重新开启以 epoch 区分历史记录。复制、CPU 更新或 clear 会清除旧绘制生产者候选。
- 对精确匹配的深度重建 PS，额外记录 t0、CB0/CB1 的绑定/已观察更新编号、CB 范围、数值视口及 sampler 的 filter/address 模式。
- CopyResource/CopySubresourceRegion 保存一层源资源与当时写入引用，不递归扩展复制图。只增加元数据，不复制额外原始纹理。

这些都是调用前绑定和写入意图。`complete_write_history_verified=false` 保持不变：未完整追踪 compute/UAV/间接绘制、成功写入、颜色/模板覆盖，也没有捕获全部生产者阶段字节。depth attachment 的绑定不直接归为 PS 生产结果。用于定位接下来的静态审计入口，不能自动授权光照改动。

## r3 当前帧核对结果

本次单帧已完成，91,258,656 字节全量 SHA 核对通过，采集后自动 stop。当前 t10 的 PS/VS 与历史深度重建程序完全一致，生产者和消费者的视口一致，sampler 为 point/clamp。相机缓冲区对象、生命周期、范围和最后观察到的更新编号均一致，补齐了旧回放的关键绑定证据。

深度 t0 是消费者深度附件对象的一次复制，源/目标均为子资源 0；但复制后仍有新的深度绘制意图，不能声称消费者读回的附件内容就是当时复制的全部内容。生产者 Common 缓冲区与消费者不是同一对象，其当时的字节没有单独读取。位置属于深度重建链，仍不是独立几何位置。

法线观察到全屏路径 2090 次 RTV 绘制、网格路径 28 次；前者保留的 16 个 shader 身份已截断，后者有 9 个，最后程序均与历史候选匹配。它们只是写入候选，不能把最后一次绘制提升为全图法线来源或玩家对象。

复用此前咖啡馆的两帧，按原始 PS 的固定布局解读四个区域：三个局部类型为 3/3/2，另一个类型 0 在 shader 中跳过空间矩阵。对应索引、类型、环境索引、插值范围和优先级保持一致；没有重新排序寻找最优匹配。将区域的 view→region 矩阵乘以 camera 的 world→view 后，三个局部矩阵的最大元素差分别约 1.03e-6、5.52e-7、5.88e-7，支持世界参考下固定区域的解释。类型 0 的矩阵不参加该比较。SH/颜色参数也变化，因此不能视作冻结时间/天气的纯镜头实验。

可复现工具：`tools/audit_native_volume_space.py <前一帧 manifest> <后一帧 manifest> <新输出 JSON>`；已用已知世界固定区域、随相机移动的反例以及全局未用矩阵/缓冲区越界检查验证。见 [脱敏实机摘要](validation/native-live-producer-r3-2026-10-09.json)。原始矩阵、地址及采样指纹保留本地。
