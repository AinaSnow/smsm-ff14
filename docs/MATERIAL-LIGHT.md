# 材质合成阶段单灯：第四轮离线证据

2026-10-08，国际服 `2026.09.15.0000.0000`。本轮完成实际材质合成渲染、单灯插入、目标精度对照及默认关闭的不可变候选。没有写入客户端、推送或发布；游戏显示和硬件成本仍未验证。

## 注入位置与保留的逻辑

历史资源追踪详见 [LIGHT-INJECTION-AND-PRECISION.md](LIGHT-INJECTION-AND-PRECISION.md)。本轮只修改已审计的全屏材质合成 `415a922293923fa4`：在读取 `t3` 漫反射光之后、原版 AO 和材质计算之前加入单灯 irradiance。

原版 `t10` 已提供视空间位置，`t5` 是编码法线和材质索引，`b1[0:3]` 将法线转换至视空间。新 helper 直接使用这些输入，不重复反推深度；离线同时核对旋转、右手坐标、斜面、偏移视口与抖动几何。灯参数仍为位置、线性 RGB、强度和范围，采用 Lambert/pi、距离衰减与连续范围截止。

这使单灯增量绕过前一阶段的 R11G11B10 写入，之后继续走原版材质、AO、环境反射、自发光、alpha、开方和曝光。只插入代码和扩展临时寄存器，原指令、接口和常量范围均审核；零强度直接返回原字节码。**保留计算逻辑不等于所有最终通道数值不变**：原版环境高光与 alpha 本来就可能依赖漫反射能量，测试以完整原版输出作为对照。

没有增加灯具自己的镜面 BRDF。本轮白色、肤色、蓝布是合成反照率色块，不是已确认适配的真实皮肤、头发或布料。金属测试中漫反射被抑制；这一场景的环境高光因原版权重已饱和而保持不变，不推广为所有金属场景都完全不受影响。

## 实际渲染与独立判据

`tools/validate_material_light.py` 执行原版 DXBC 和插入后的 DXBC，通过 D3D11 WARP Draw → staging Copy/Map 读回结果。不是只检查编译或 CreateShader。

原版对照的输入为 `原漫反射纹理 + 独立 CPU 几何求得的灯光`，候选输入保持原漫反射纹理不变，由 shader 内部加灯。随后两者都执行完整原版材质流程。白色、肤色、蓝布等简化材质另与独立 `sqrt(albedo × diffuse × AO + emission²) × exposure` 核对，避免只用同一实现互相证明。

最新结果：`artifacts/material-light-validation-v4/report.json`，**62 项检查通过**。

| 检查 | 结果 |
|---|---|
| CubeArray/FP16 工具校准 | 六个不同颜色方向及非单位 alpha 均精确读回；验证新资源绑定和半精度输出 |
| 11 类材质配置 | 白色、肤色、蓝布、金属、混合金属、AO、零 AO、自发光、曝光、非零高光 alpha、自发光 alpha；原版对照 RGBA 最大误差 5.96e-8 |
| 独立简化材质公式 | 最大误差 1.13e-7；白灯乘反照率后的线性色彩响应一致 |
| 5 组坐标配置 | 完整材质输出与原版输入对照最大误差 5.96e-8 |
| 烘焙参数候选 | 左暖、右冷、短范围、表面背后、范围外；完整材质对照通过 |
| 离线动态控制 | 同设备 b13 更新 13 帧，受光质心 x 从 16.39 到 46.61 单调右移；逐帧最大误差 1.12e-7 |
| 确定性与坏输入 | 灯移开再返回完全一致；helper 的零位置、NaN 位置、零/NaN 法线贡献为零 |
| FP16 最终输出 | 四组亮度下候选与原版加光输入的最终 FP16 输出逐像素完全一致 |

动态 13 帧验证针对离线 helper；完整材质用多个烘焙灯位验证。游戏包没有 b13 控制通道。坏输入检查也仅针对 helper，不承诺原版材质 shader 能处理任意损坏的 G-buffer。

`material-comparison.png` 三列依次为原版、加灯、正向差分 ×40；三行依次为白色、肤色色块、蓝布。它是实际数值输出的预览，不是游戏截图；差分放大不能代表正常观看时的可见程度。

初次 v1 运行发现自发光测试纹理的启用 alpha 设为 0，触发原版关闭自发光分支，导致独立公式检查失败。已按原指令修正测试输入并新增非零 alpha 断言；没有为让测试通过修改原版算法。失败产物保留，最终以 v4 为准。

## 两种注入位置的精度对照

固定同一几何、白灯强度 2、范围 8、白色反照率 0.8，每组 2560 个有正向贡献的像素。先用真实 GPU 目标写入得到同一 R11G11B10 基线 B：

- 旧路线：`B + 灯` 再写 R11G11B10，送入原版材质合成，写 FP16 场景目标。
- 新路线：直接读取 B，在材质 shader 寄存器中加灯，再写 FP16 场景目标。
- 精度参考：原版材质 shader 读取未再次量化的 `B + CPU灯`，写 float32；另外写 FP16 检查新路线一致性。

| 基线亮度倍率 | 旧路线增量完全消失 | 新路线增量完全消失 | 旧路线 RGB MSE | 新路线 RGB MSE |
|---|---:|---:|---:|---:|
| 0.25 | 12.50% | 0% | 1.424e-6 | 1.928e-8 |
| 1 | 55.63% | 3.44% | 4.565e-6 | 8.066e-8 |
| 4 | 95.63% | 30.16% | 4.097e-6 | 3.259e-7 |
| 16 | 100% | 90.94% | 2.183e-6 | 1.285e-6 |

新路线四组数值误差均降低，但最终 FP16 仍会吞掉很小的增量，强背景下尤为明显。这是合成数据的精度收益，不是游戏画质、可见度、性能提升或历史景深/反射差异小的原因证明。与第三轮表格的阶段、基线和统计终点不同，数值不能直接混用。

## 下一步及实机门槛

先扩展审计另一条 `980154264a89fba1` 材质路径的顶点输入、深度、材质条件和覆盖范围。当前包只替换一个路径，不能声称人物、透明对象、头发和全部画质设置均被覆盖。此前屏幕空间遮挡研究尚未接入本候选；目前可穿墙，缺少离屏、背面、隐藏和透明几何信息，原版 AO 不是此灯的投影阴影。

之后才做一次小范围实机判定：隔离单灯、固定相机与曝光，对照无灯及已验证的左右灯位，核对实际目标覆盖和表面受光移动，检查白衣/肤色与错误漏光；性能另做同条件帧时间采样。若目标路径未覆盖所选对象，回到资源审计，不要求用户继续盲找差异。离线 WARP 耗时不换算实际显卡 FPS。

世界固定灯位、连续游戏内交互、多灯和 SSGI 尚未实现，不复用 r5 动态参数机制。
