两者都在原来的三条 `dp4_sat` 与 `cb6[3].w` 缩放之后、原距离衰减之前替换一次环境漫反射。使用同一个原生 `v6.xyz` 位置，保持原来的法线来源、材质色表、AO、反射、透明/裁剪和曝光计算。原 alpha 输出包含与颜色相关的编码，因此保留其计算指令，不宣称改变光照后 alpha 数值必定不变。

服装的原生反射 cube-array 已占用 `t12`，故新候选显式改用 `t14`；原 binding 声明和反射路径保留。补丁器只接受三个逐一审计过的身份，检查完整 SH 指令前缀及空闲槽，恢复检查证明原指令流在有界插入之外保持不变。旧 r4 默认目标生成的候选 SHA 与原包逐字节相同。

已对 r7 捕获到的实际 VS 做静态复核：头发 VS `972493e7d05b8002`、裙装 VS `8ac278fab6687209` 都把 `r22.xyz` 输出给 `o6.xyz`；同一 `r22` 经相机反射中的 MainViewToProjection 矩阵生成 clip position。该证据支持沿用原生主视图位置，不冒充完整骨骼/世界坐标回放。游戏中的新路径相机关联仍由运行时同帧、同对象/范围保护检查。

区域形状、SH 数学和失效回退沿用 r4 已验证的实现：球/盒/柱，原生顺序层叠；只有全局区域、缺失/非法输入时保留原结果。没有额外新增台灯，不放大游戏原生系数来制造差别。

## 验证

- 24 项 WARP 实际材质绘制检查、38 个 draw jobs：两个原始 shader 的完整输出与独立几何生成的原生漫反射输入 oracle 比较；三种形状、半强度、原衰减、FP16、原裁剪、缺失/异常回退，以及非零反射、方向 SH、不同法线、材质表和纹理数组的等系数无变化检查。
- 运行时桥以真实像素验证 `t14` 选择、`t12` 原资源保留、PS/SRV/有范围 CB 的恢复、未知身份拒绝及每变体计数。现有相机/帧/更新失效保护继续通过。
- 官方 ReShade 硬件 host 对两个精确原始 PS 分别绘制三顶点。通过原全屏来源入口复制区域数据，半强度候选输出与 WARP 预期最大误差约 `5.96e-8`，关闭后与本机原输出差为 0；每次只有对应变体的计数增加。
- 模拟 r7→r8 升级、中断恢复、r10 恢复、runtime/配置保留和已有命令能力检查通过。

合成测试中的颜色变化是受控对照，不能用于预测咖啡馆实际改善幅度。原场景中的对象环境项可能已经接近表面取样结果；实机收益、稳定性和 GPU 成本尚未验收。摘要：[r8 验证](validation/native-visible-r8-2026-10-09.json)。
