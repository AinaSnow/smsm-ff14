# SMSM 开发计划：回归 3DMigoto（2026-10-10 修订）

本版取代同名计划的前一版本（见 Git 历史）。R0/R1 的执行细节、崩溃证据和部署记录保留在
[3DMIGOTO-COMPATIBILITY.md](3DMIGOTO-COMPATIBILITY.md)，不在这里重复。

## 为什么修订

移植到 `2026.09.15` 客户端后，日常包里真正开启的只有“50% 游戏色调 + 50% SMSM 色调”这一项。
原 SMSM 的其余效果（反射、光束/径向模糊、去色带抖动、景深、法线阴影）要么默认关闭未验收，
要么尚未重新适配。原生灯光支线已冻结；但回归后的 H1→H3 又在 50% 混合之后叠加 ≤6% 的高光衰减，
改动量级低于实景截图能可靠分辨的范围，所以连续得到“不确定”。

根因在色调本身。读 `72a656dfd52149ad` 源码可见，SMSM 路径：

- 没有使用游戏的场景 tone LUT（`sToneMap`，各地区的调色和色温都在这里）；
- 只通过 `whitePt` 间接考虑曝光；
- EVILS 曲线逐通道套用，亮部的肤色、浅色衣料会向白色偏移。

这正是 r4–r6“偏白”的来源。r7/r8 用降低混合比例绕开，PORTING 当时已写明应改曲线本身而不是继续降比例，
但后来没有执行。本修订把它列为第一项。

## 原则

- 一次只做一个效果；每个效果的验收 = 同场景开/关截图 + 一句结论 + 是否默认开启。
- 离线 WARP 读回只在 shader 接口、绑定或编译方式变化时做；纯数学调整只做编译、接口检查和数值抽样。
- 管理器、事务安装、回退已经够用，不再扩展工具链。
- 小于肉眼可辨的改动不作为候选提交给用户对比；候选之间要有明显差别，让用户选，而不是让用户找差别。
- 文档：README 写当前状态，本文件写计划，每个效果一份短记录。不新增“证据边界”类长文。

## 阶段

### R1 收尾（只剩一项）

c2 配置规避（Dalamud `IsDisableViewport=true` + 3DMigoto 1.3.16）已实际使用，窗口操作正常。
**已关闭**：2026-10-11 用户确认色调 A 下切图正常。纯净 A/C 组合不再补测：离线已复现崩溃路径，规避已生效。
如切图出问题，保存日志/dump 再处理。

### T1 色调曲线预设（当前）

候选包 `r11-tone-presets-t1`（`tools/build_tone_presets.py`，记录见 [TONE-PRESETS-T1](TONE-PRESETS-T1.md)；用户已选定 A，A 默认版已部署），基于 c2，只改 tone shader 和 INI 按键。Ctrl+F8 循环四种模式，
左上角标签显示当前模式（Ctrl+F7 隐藏）：

| 标签 | 内容 | 要验证的假设 |
|---|---|---|
| R10（蓝） | 现行 50% 混合，作为基线 | — |
| A（绿） | 100% SMSM 曲线，作用于最大通道，保持色相 | 偏白来自逐通道曲线的色相偏移 |
| B（橙） | 游戏色调的颜色 + SMSM 曲线的明暗 | 保留游戏地区调色，只换掉灰雾感的明暗曲线 |
| C（紫） | 同 A，但接近白色的高光逐渐回到中性白 | A 的亮灯、日光下衣料可能过艳；C 只在高光段处理，中间调肤色不变 |

验收：在 2–3 个不同场景（白天户外、室内暖灯、有角色近景）截取四种模式，用户选一个。
选中的作为默认（没有一个优于 R10 就保留 R10 并结束色调项，不再做 H 系列式的小幅修补）。
可以在选中方案上做一次强度微调，然后发布候选版本。

H1–H3 高光衰减停止，记录保留。

### T2 已移植的低风险效果转正

这些 shader 已移植过，只是默认关闭。每项一个开关对照，决定是否默认开启：

1. 去色带抖动（**完成，默认开**）：r10 的输出拷贝 `23d27700572e0c4d` 实机不在显示路径上（DLSS/FSR 均无指示），改为在色调 shader 内抖动 + 暗角 `782e995758bf001d`；候选 `r11-dither-t2b`，见 [DITHER-T2](DITHER-T2.md)——天空渐变对照。
2. 光束 / 径向模糊（**完成，默认 SMSM**，T2d，见 [RADIAL-T2](RADIAL-T2.md)）：`91f970e6bbe57d99`——有光束的场景对照。
3. SMSM Bloom（**跳过，保留游戏 Bloom**：2026-10-13 雨夜灯光截图光晕柔和、无块状/色带，见 `docs/validation/bloom-check-2026-10-13.json`）：`98b1…`、`5813…`、`d0bc…`、`a617…`。

部署 T2d 时管理器发现客户端从 2026.09.15 更新到 2026.10.06 并拒绝安装。重新提取：31,018 个唯一 shader
