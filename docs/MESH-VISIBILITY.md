# 网格材质的深度遮挡：第九轮

2026-10-08。单灯遮挡已在离线原版网格材质 `980154264a89fba1` 中执行，支持关闭/开启柔和漫反射。新灯和遮挡合入同一次绘制，原版法线贴图、材质流程、alpha、裁剪和输出编码继续执行。没有新游戏包或客户端修改。

## 输入与插入位置

新增 `tools/patches/forward_visibility.hlsl`：接收注入点的最终法线 `r1` 与视空间位置 `v6`，从原材质已有的 t2 深度、t4 编码法线、s0 采样器和 b3 相机行读取场景表面。**这里只验证合成输入**，没有推断游戏实际绑定内容。

离线 b12 提供投影、视口映射和逆投影，b13 提供灯参数。b12 的 10 个 float4 是专用 harness 布局，与全屏材质的 6 个 float4 区分；游戏 patcher 仍拒绝它们。`fuse_material_visibility.py` 仅在显式 `mesh=True` 时采用网格输入寄存器映射和原版法线校正之后的插入点，不扩大游戏资源白名单。

深度先按最近纹素中心取样，再用该中心的 UV 和逆投影重建位置。使用步进点 UV 搭配另一个纹素的深度会在斜面引入坐标不一致，因此位置/法线与投影的校准先于阴影比较。

测试 VS 生成视空间 z=5 的接收平面，深度图含 z≈3 的有限遮挡平面；原 PS 会裁掉被前景深度遮住的接收面。该 PS 要求采样深度与光栅深度之间为正间距，测试显式给光栅深度 `1e-5` 偏移，不冒充已恢复的游戏光栅状态。未回放实际网格或蒙皮。

## 本轮验证

`tools/validate_forward_visibility.py` → `artifacts/forward-visibility-validation-v8/report.json`，**216 项离线检查通过**，包括实际 D3D11 WARP 绘制/读回与接口拒绝检查。

- 透视、正交、斜面、薄遮挡物、高分辨率、投影抖动、偏移视口及四组预留角度。纹素中心重建最大误差约 `4.77e-6`，最终材质对照最大误差约 `1.19e-7`。
- 原版材质输入的独立 CPU 灯计算对照；肤色参考、法线贴图、半 alpha、全裁剪、金属、湿润以及数值材质分支 1/2/3。数值分支不擅自命名为真实皮肤/头发。
- 被遮挡的新增灯归零时，原场景光照保留；原版裁剪/深度拒绝的像素不会被新增灯复活，alpha 保持。
- Lambert 与 bounded `.5` 都执行完整材质合成；平面和 55° 斜面各有同设备 13 帧连续灯位更新及逐帧原生材质对照。
- 零强度严格等于原版；屏幕外、缺失深度、奇异逆投影均验证诊断掩码和最终材质回退。真实隐藏几何缺失仍造成 **1393 个参考内部像素漏光**，作为限制记录。
- 实际源 alpha 混合和 FP16 输出检查通过；这些是测试状态，不是已恢复的游戏混合/深度状态。

图 `mesh-shadow-comparison.png` 三列为无遮挡新增灯、深度遮挡后的新增灯、独立有限平面几何参考。黑色矩形是被原 PS 裁掉的接收平面，前景物体本身未绘制；不是完整场景截图。

## 斜面复核修正

首次接入发现 65° 场景的 57 个几何阴影像素全部漏掉。原因定位到局部平面命中后的验证：最近纹素中心与命中点即使位于同一斜面，z 值也可能不同。

新增显式 `VISIBILITY_PLANE_DISTANCE=1` 实验分支，将复核从 `abs(verify.z-hit.z)` 改为 `abs(dot(verify-hit, normal))`。偏置 `.0125`、厚度 `.2`、最多 128 步均保持不变。原分支保留；全屏材质默认仍走原分支，只有本轮网格候选显式启用新分支。

|---|---:|---:|
| 初始八场景合计 | 465 | 409 |
| 其中 65° 漏阴影 | 57 | 1 |
| 预留 -40° | 27 | 13 |
| 预留 40° | 75 | 75 |
| 预留 55° | 222 | 5 |
| 预留 70° | 167 | 62 |
| 四组预留角度合计 | 491 | 155 |

四组预留角度在改动前确定，观察结果后未调参数。统计保留全部接收面边缘像素，包含误遮挡和漏阴影；55° 的误遮挡从 1 增到 2，不能宣称每个指标都改善。窄物体、视口边缘和高分辨率仍有误差。

## 回归与复现

原 marcher 抽成 `visibility_march.hlsl` 供两路径使用；没有修改共享 renderer。全屏遮挡 **162 项**回归、柔和漫反射 **182 项**回归通过。全屏融合 shader 的 SHA-256 与上一轮相同，柔和漫反射候选的 SHA-256 也保持相同。旧包管理/回退与两个离线布局隔离共 **10 项测试通过**。

接口回归使用固定的 `forward-visibility-validation-v8` 产物，验证游戏 patcher 拒绝附加投影缓冲，以及全屏离线布局拒绝网格 helper。游戏目录、旧不可变包、DLL/INI 都未改动。

下一步仍须验证实机相机常量、数值视口及无损深度/法线的重投影，再安排少量实机灯位/遮挡对照。标准深度路径的结果不能推断原 PS 支持反向 Z；屏幕外、隐藏、透明遮挡、两条路径像素重叠和真实 GPU 成本尚未解决。
