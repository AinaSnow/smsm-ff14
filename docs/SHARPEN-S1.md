# S1 / S2：锐化

2026-10-11。候选包 `artifacts/r11-sharpen-s1`（`tools/build_sharpen_s1.py`），基于 T2b（色调 A + 抖动）。
**已部署，下次启动生效：色调 A + 抖动开 + 锐化中。**

## 想解决的问题

用户反馈角色头发边缘发软（当时 DLSS；两张抖动开关截图一样软，与色调/抖动无关）。用户随后改用 DLAA。
预期：发丝、睫毛、布料纹理更清楚，不出现白边或亮点噪点。

## 做法

色调 shader 已确认输出到屏幕，锐化放在其开头、两条色调曲线之前，作用于 HDR 输入：

- 参考 AMD FidelityFX CAS：中心 + 上下左右 5 点；局部对比已高的地方少锐化。
- 在 `u = c/(1+c)` 压缩域计算，高光不会冲高；结果限制在这 5 点的最小/最大值之间，不产生光晕。
- 强度 x6：中 0.5（CAS 峰值 −1/6.5）、强 1.0（−1/5，CAS 上限）。alpha 不变。

| 按键 | 作用 |
|---|---|
| Ctrl＋F4 | 锐化 关 / 中 / 强 循环（启动为中） |
| Ctrl＋F7 | 显示标签：A、D 之后的 **S**，浅蓝 = 中，橙 = 强；关闭时无 S |
| Ctrl＋F6 / F8 | 抖动、色调，不变 |

## 离线验证

`docs/validation/sharpen-s1.json`，WARP 实际绘制：

- 锐化关：模式 × 标签 × 抖动组合与已部署 T2b 逐像素一致。
- 平坦图像开强锐化最大变化 `8.9e-8`。
- 硬边、软渐变、细条纹、纹理噪声、HDR 高光 8.0、纯黑块：输出均在输入十字邻域色调结果的最小/最大之间
  （最大越界 `9.5e-7`），无光晕；纯黑不变。
- 横向平均梯度（含平坦区域）：关 → 中 → 强 单调上升，约 +3.5% / +5%。合成硬边受防光晕限制变化很小，
  主要作用在纹理和多像素的软边，正是 TAA/DLAA 之后的情况；实际强弱需要实景判断。
- S 标签只在标签开时出现，颜色对应强度。官方 1.3.16 按原包启动：A + 抖动 + 中锐化，与 WARP 差 `1.4e-6`。
- `test_sharpen_s1.py`：相对 T2b 只改色调 shader 与 INI，精确回退。

锐化在色调 shader 内，管理器的效果选择不能单独关闭它；用 Ctrl＋F4 关。

## S2：半径 2 的反锐化掩模（当前候选，已部署）

用户选择做加强版。`artifacts/r11-sharpen-s2`（`build_sharpen_s1.py --variant s2`），同样基于 T2b，替换 S1。

先用 numpy 原型找到 S1 的根本问题：**硬性限制在邻域最小/最大之间，使细发丝（本身就是局部最亮）完全无法增加对比**
（各强度都是 0.228 不变）。S2 的改动：

- 13 点、半径 2（十字权重 2，对角和半径 2 十字权重 1），覆盖 DLAA 后 2–3 像素的软边。
- 细节项在 `u = c/(1+c)` 中计算；允许越过邻域最小/最大，但不超过 k × 局部范围，**范围在线性 HDR 中计算**。
  第一版在 u 域取上限，高光边缘在 R10 模式下从 4.6 冲到 34（会成亮点），已改正。
- 档位：中 = 2 倍、k 0.2；强 = 4 倍、k 0.4。Ctrl＋F4 循环 关 / 中 / 强（INI 值 0 / 1 / 2），启动为中；
  标签 S 浅蓝 = 中、橙 = 强。

离线（`docs/validation/sharpen-s2.json`，色调 A，输入为高斯 σ1.2 软化的场景）：

| | 关 | 中 | 强 |
|---|---|---|---|
| 边缘 10–90% 宽度 | 3.10 px | 2.09 px | 1.54 px |
| 1 像素亮丝对比 | 0.321 | 0.382（+19%） | 0.454（+41%） |
| 台阶边缘光晕 | — | 5.3% | 12.4% |
| 纹理标准差 | 0.018 | 0.024 | 0.030 |

- 锐化关：与 T2b 逐像素一致；平坦图像不变；纯黑不变；alpha 不变；无负值。
- 高光边缘最多亮 k（R10 模式 4.59 → 5.23 / 5.93；A 模式曲线饱和，几乎不变）。
- 官方 1.3.16 按原包启动：A + 抖动 + 中锐化，与 WARP 差 `4.2e-6`。
- 合成对比图 `docs/validation/sharpen-s2-synthetic.png`：发丝条纹从糊变清楚，差别一眼可见。
  **强档在很亮的高光周围会出现一圈暗边**，纹理颗粒也更明显，实景需要注意。
- S1 构建器改为可选 S1/S2；重建 S1 时 shader 逐字节相同，仅 INI 注释文字不同。

## S2b：亮处少锐化（已构建，未部署）

`artifacts/r11-sharpen-s2b`（`build_sharpen_s1.py --variant s2b`）：S2 加一行亮度渐弱。取 13 点中最亮通道，
按 SMSM 曲线和白点换算为显示亮度 d，锐化量乘以 `1 − smoothstep(0.9, 1.05, d)`。档位、按键、标签与 S2 相同，启动为中。

阈值依据用户截图：夜景浅色头发屏幕值约 0.67–0.76，灯罩约 0.94–0.98。最初按 0.75–1.0 设计会削弱白天浅色头发，
改为 1.0–1.1 后小灯（核心 3.0）周围几乎不起作用；比较 1.0–1.1 / 0.9–1.05 / 0.85–1.0 / 0.8–1.0 后选 0.9–1.05：
再往下降，暗圈不再减少，只会损失头发锐化。

离线（`docs/validation/sharpen-s2b.json`，合成场景含两盏带光晕的灯）：

- d ≤ 0.9 的像素与 S2 **完全相同**（差 0）：发丝、边缘、纹理锐化不变。
- 邻域 d ≥ 1.05 的像素与关闭相同（差 ≤ 3e-6）。
- 灯周围最大暗化（色调 A）：中 0.125 → 0.070，强 0.255 → 0.144，约减半。
- 剩余部分来自光晕本身的陡峭衰减：这些像素邻域并不亮，按亮度无法与细节区分。
  对比图 `docs/validation/sharpen-s2b-lamps.png`：S2 灯边发硬、两灯间隙变暗；S2b 接近关闭。
- 锐化关与 T2b 相同；官方 1.3.16 按原包启动：A + 抖动 + S2b 中，与 WARP 差 `2.7e-6`。
