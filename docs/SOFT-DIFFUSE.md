# 新增单灯的柔和漫反射实验

2026-10-08，第八轮。本轮针对新增单灯的角度响应，不替换全游戏的原有漫反射，不实现面光源、次表面散射、间接光或软阴影。离线合成输入实际执行原版材质 shader；没有写入客户端或创建游戏包。

## 曲线与选择

令 `x = saturate(N·L)`、`s ∈ [0,1]`。原单灯为 `x/π`，本轮比较两种响应：

| 配置 | 响应 | 性质 |
|---|---|---|
| 默认关闭 | `x/π` | 保留上一轮程序 |
| bounded，优先实验 | `((1-s)x + s·x²(2-x))/π` | 不超过原 Lambert，背面为零、正面峰值相同；中间亮度会降低 |
| balanced，仅对照 | `((1-s)x + s·x²(3-2x))/π` | 均匀半球方向下响应积分相同，但部分角度会增亮 |

bounded 的明暗交界处斜率从 `1/π` 降到 `(1-s)/π`；`s=1` 时斜率为零。它改变明暗过渡，不扩展受光到背面，也不改变遮挡掩码的硬边。三个 RGB 分量乘同一标量，避免曲线直接引入色偏；完整原生材质仍可能根据漫反射计算其他通道，因此最终 RGBA 另作原版输入对照。

bounded 的均匀半球响应积分为 `1-s/6`，`s=.5` 时约 0.91667。这是明确的亮度取舍，不做能量补偿，以免重新增加高光。积分和峰值约束不代表物理 BRDF 验证，也不代表真实皮肤/布料已经适配。

## 实际渲染证据

`tools/validate_soft_diffuse.py` 生成 `artifacts/soft-diffuse-validation-v2`，**182 项检查通过**，最大数值对照误差约 `2.38e-7`。候选强度 0/.5/1 均在原版材质处理之前加入；原构建器默认 `softness=0`。此设置只在本地构建参数中可调，尚无游戏内 UI。

- 2049 个法线夹角采样：背面零、单调性、峰值、RGB 同比例、半球响应积分及交界斜率。另实际渲染 balanced 对照，记录其中间角度增益。
- 全屏材质路径：白色、肤色参考、蓝色、AO、零 AO、金属、混合金属、自发光、曝光；对照 CPU 独立计算的灯输入加原生材质，检查完整 RGBA。
- 网格材质路径：白色、肤色参考、法线贴图、掠射、半透明 alpha、裁剪、深度拒绝，保留原版材质流程及原 alpha。
- bounded `.5` 与已有屏幕空间遮挡合为单次 GPU 绘制；同设备 13 帧移动灯位，最终材质与参考一致，阴影里保留原场景光照。
- 强度/范围仍沿用单灯定义；背向点光源的平面输出等于原版，FP16 合成误差不超过一个存储 ULP。
- 两个默认 helper 的可执行指令与此前产物完全相同，非法 softness 拒绝构建。

共享入口增加默认关闭的分支后，上一轮融合遮挡 **162 项实际渲染回归通过**，产物 `material-visibility-fused-v4` 的两份融合 shader SHA-256 与 v3 相同。原包管理及离线/游戏接口隔离 **8 项测试通过**；没有修改共享 renderer。

## 白衣与肤色的高光检查

先前 balanced 首次实验虽然通过数值验证，却增加了超范围像素，因此保留作对照，优先使用 bounded。下表为 `.5` 强度的风格曲线、6144 像素合成场景中**任一原生输出颜色分量大于 1**的像素数；读回时不截断数值。这是显示前输出范围统计，不是显示器校准，也不是实际游戏过曝鉴定。

| 参考材质 / 灯强度 | Lambert | balanced | bounded |
|---|---:|---:|---:|
| 白色 / 18 | 0 | 0 | 0 |
| 白色 / 60 | 150 | 175 | 147 |
| 白色 / 120 | 1876 | 1985 | 1834 |
| 肤色 / 18 | 0 | 0 | 0 |
| 肤色 / 60 | 0 | 0 | 0 |
| 肤色 / 120 | 827 | 904 | 809 |

在这些漫反射材质样本中，bounded 的最终 RGB 逐像素不高于 Lambert（浮点误差容限 `2e-6`），没有新增超范围像素；较强灯光仍会超范围，不能把曲线当作曝光修复。合成肤色色块不是真实角色皮肤，没有肤质、纹理或次表面散射的自然度证据。

`soft-diffuse-comparison.png` 每行是白/肤色/蓝色参考材质；四列依次为 Lambert、bounded .5、bounded 1、有符号差分放大 8 倍。最后一列 0.5 灰色表示零差异；它不是额外滤镜或游戏效果图。

## 复现与边界

仓库根目录执行，输出目录必须不存在：

```powershell
C:\Python314\python.exe tools/validate_soft_diffuse.py artifacts/soft-diffuse-new
C:\Python314\python.exe tools/validate_material_visibility.py artifacts/material-visibility-fused-new --bias .0125 --thickness .2 --steps 128 --fused
```

`patch_material_light.compile_helper` 与 `patch_forward_light.compile_helper` 新增只限关键字的 `softness=0`、`soft_profile='bounded'`。启用时从同一 `diffuse_response.hlsl` 编译两路径；`balanced` 显式选择，所有现有包构建器仍使用 0。未发布实验包、未安装、未修改 DLL/INI，不使用 r5 动态机制。

实际显卡耗时、运动稳定性、真实人物自然度尚未验证。原有屏幕外/隐藏/透明遮挡限制和游戏投影数据缺口仍在；本轮没有新增景深或反射画质结论。后续继续真实投影数据验证与网格遮挡研究；风格化方面尚待冷暖阴影、卡通分层、轮廓光、细描边与材质高光，独立开关逐项验证。
