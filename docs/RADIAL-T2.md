# T2：光束 / 径向模糊

2026-10-13。`91f970e6bbe57d99` 的 r10 移植版（SMSM 8 次带抖动采样），加游戏 / SMSM 开关。

## 想解决的问题

游戏原版只用 4 次等距采样，光束可能出现台阶感或分离的残影；SMSM 用 8 次带交错梯度抖动的采样，光束更平滑、连续。
总能量归一化相同，整体亮度不应变化。
