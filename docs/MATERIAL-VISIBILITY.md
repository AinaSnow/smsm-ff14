# 材质阶段遮挡：第六轮离线证据

2026-10-08，国际服 `2026.09.15.0000.0000`。本轮把屏幕空间遮挡送入真实原版材质合成，验证完整输出，而不只看遮挡掩码。基准参数和候选参数各 **113 项实际渲染检查通过**。没有创建新游戏包、修改现有包或写入客户端。

## 实际执行链路

```text
已知几何的视空间位置/法线 + 原漫反射纹理
→ GPU：计算单灯与屏幕空间可见性
→ 输出 原漫反射 + 新灯 × 可见性
→ 浮点读回，再上传纹理
→ GPU：执行原版 415a922293923fa4 材质合成
→ 最终 RGBA 读回与独立几何参考比较
```

中间明确存在 CPU 读回/上传，不是游戏内常驻 GPU 链路，也不能据此测算游戏性能。可见性只调制新增灯光；被挡住后恢复原有光照，不能把整幅场景或自发光乘黑。

`material_visibility.hlsl` 使用材质路径对应的 t10 位置和 t5 法线接口，复用 `material_light.hlsl`。投影/视口转换由 **离线 b12** 提供，灯参数用离线 b13。没有将它们伪装成游戏现成绑定；实际跨阶段资源和参数绑定尚待审核。

可见性保留两种模式：假定厚度内命中，或再用局部法线平面求交并在交点复核深度。另有无遮挡开关。已确认命中优先保留；出屏幕、无效位置或无法投影会标记 unsupported 并回退为无遮挡。屏幕中完全不存在的隐藏物体不能自动识别为“缺失物体”。

## 合成与几何检查

基准参数：偏移 0.025、假定厚度 0.35、最多 96 步。结果为 `artifacts/material-visibility-validation-v2/report.json`，113 项通过。

- 九组几何：正面、倾斜、掠射角、薄片、高分辨率、投影抖动、反向 Z、右手坐标、偏移视口。
- 接入正确性：GPU 可见性与独立 CPU 灯光组合为参考输入，再执行原版材质 shader。几何正确性则用已知有限平面与灯光线段求交，统计全部接收面的误判，保留边缘失败。
- 检查无遮挡开关、能量边界、原光照保留和白色参考的 alpha；补充肤色色块、蓝布、AO、自发光/非零 alpha、混合金属/高光的完整 RGBA 对照。
- 13 帧灯移动同时测量掩码与最终颜色，帧间变化以真实移动阴影为参考，而非要求变化为零。
- 离屏、缺失遮挡物、无效位置、退化投影均检查回退。缺失遮挡物时仍有 **637 个几何参考内部像素漏光**，记录为能力限制，不宣称已修复穿墙。

基准厚度命中的九组误判为 **1606**，局部平面复核后为 **779**。基准设置的最终颜色帧间变化误差从约 0.000432 增到 0.000464，不能把静态误判减少称为运动稳定性改善。

## 参数筛选与预留验证

`sweep_material_visibility.py` 比较六组参数。先只用正面、倾斜、薄片选择误判总数最低者；写出 `selection.json` 冻结选择后，再渲染其余六组几何。预留结果不用于重新选参数，也不自动修改游戏包。

候选 `balanced-128`：偏移 **0.0125**、假定厚度 **0.2**、最多 **128 步**。结果在 `artifacts/material-visibility-sweep-v2/report.json`。

| 参数 | 三组筛选几何误判 | 六组预留几何误判 |
|---|---:|---:|
| 既有平面复核基准 | 193 | 586 |
| 更小偏移，96 步 | 430 | 172 |
| 更小偏移，128 步 | 430 | 208 |
| 更薄假定厚度，128 步 | 430 | 208 |
| balanced-128 | **69** | **208** |
| balanced-64 | 192 | 721 |

更小偏移在预留集上较好，但筛选集明显较差；没有看完预留结果后改选它。balanced-128 在六个预留场景上均未相对基准退步，总误判减少约 **64.5%**。仍是固定合成几何家族，不等于游戏场景泛化证明。

候选单独运行完整 113 项检查，结果在 `artifacts/material-visibility-balanced-v1/report.json`。九组误判从原平面复核的 779 降到 **277**，约减少 **64.4%**。本组没有误加阴影，剩余均为漏遮挡：正面 57、倾斜 12、高分辨率 58、反向 Z 57、右手坐标 57、偏移视口 36。薄片和掠射样本为零，不推广为任意薄物体均可处理。候选材质对照最大绝对误差约 **3.58e-7**。

## 运动与成本仍有取舍

下表比较既有平面复核参数与 balanced-128，不把真实阴影移动误判为不稳定。

| 序列 / 指标 | 基准 | balanced-128 |
|---|---:|---:|
| 既有序列：最终 RGB 平均误差 | 0.000779 | 0.000400 |
| 既有序列：最终 RGB 帧间变化误差 | 0.000464 | 0.000436 |
| 预留序列：最终 RGB 平均误差 | 0.000875 | 0.000421 |
| 预留序列：最终 RGB 帧间变化误差 | 0.000769 | 0.000762 |
| 预留序列：掩码帧间变化误差 | 0.007261 | **0.007365（略差）** |

候选降低最终颜色误差，但没有同时改善所有运动指标，也没有时间滤波或稳定器。报告明确标记 `all_motion_metrics_nonregressing=false`、`eligible_for_default=false`。扫描的有限数值检查通过不等于画质验收通过。

最多迭代数从 96 增到 128，增加约三分之一；实际有提前退出，不能换算 GPU 毫秒或 FPS。尚无实际显卡计时。

## 产物与复现

`material-shadow-comparison.png` 三列为无遮挡、遮挡新灯后的原版材质输出、独立几何参考。它是合成输入实际渲染，不是 FF14 截图；原浮点文件为数值依据。

仓库根目录执行，输出目录必须不存在：

```powershell
C:\Python314\python.exe tools/validate_material_visibility.py artifacts/material-visibility-new
C:\Python314\python.exe tools/sweep_material_visibility.py artifacts/material-visibility-sweep-new
C:\Python314\python.exe tools/validate_material_visibility.py artifacts/material-visibility-balanced-new --bias .0125 --thickness .2 --steps 128
```

保留输入、shader、原始读回、几何掩码、设置和源码 SHA-256。候选设置显式记录，没有更改默认参数。本轮未修改共享 renderer、旧包构建器、景深或反射，不重复无关回归，也没有新增它们的画质结论。

## 下一步边界

先审计游戏如何向材质阶段提供投影、视口与可用深度，再对网格路径建立遮挡合成对照，之后决定游戏包的绑定方式。未验证前不读取猜测的常量槽，不使用旧 r5 动态机制，不热换 DLL。

屏幕空间方法缺少离屏、背面、隐藏和透明遮挡几何；法线贴图的着色法线也未必是几何平面法线。有限步进、假定厚度和硬边仍可能漏光、跳动。当前证据足以继续研究，尚不足以宣称完整阴影或实机可用的动态灯。
